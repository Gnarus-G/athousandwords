# Visual Communication

A shared visual communication channel between a person and agents working in different harnesses.

## Language

**Visual**:
A diagram, image, drawing, or other rendering an agent presents to communicate an idea.
_Avoid_: Artifact, post

**Visual surface**:
The space in which a person receives and views visuals from agents.
_Avoid_: Whiteboard (unless referring specifically to an editable drawing space)

**Visual feedback**:
A person's response tied to a particular visual, such as a comment or selection, intended for the presenting agent.

**Companion**:
The person's visual communication environment, shared by the agents presenting to them.

**Workspace**:
A conversation's collection of visuals and visual feedback within the companion.
_Avoid_: Session (when referring to the collection rather than a connection's lifetime)

**Revision**:
A particular version of a visual, retained when that visual is updated.
_Avoid_: Visual (when referring specifically to one version)

**Comment**:
Written visual feedback about a particular revision as a whole.
